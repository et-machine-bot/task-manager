# チームタスク

チームの作業を、このパソコンのブラウザで管理するアプリです。ログインはありません。タスクも担当者の名前も、このパソコンの中だけに保存されます。

## できること

- タスクを追加する、編集する、削除する
- 担当者を一覧から選ぶ。新しい名前を入力すると、その場で登録される
- 期限と、進み具合（未着手 / 進行中 / 完了）を記録する
- 担当者と進み具合で一覧を絞り込む
- 完了していなくて期限を過ぎたタスクを、赤い表示で知らせる

## 1. 最初の準備（最初の1回だけ）

準備は、アプリのフォルダで行います。黒い画面（ターミナル）を開いて、次の順番どおりに進めてください。

1. アプリのフォルダへ移動する

   ダウンロードした場所や、デスクトップなど、このアプリ一式が入っているフォルダを指定します。次の `cd` のあとを、実際のフォルダの場所に書き換えてください。

   ```bash
   cd アプリのフォルダ
   ```

2. 仮想環境を作る

   Windows（PowerShell またはコマンドプロンプト）:

   ```bash
   py -3 -m venv .venv
   ```

   `py` が使えないときは、次を試してください。

   ```bash
   python -m venv .venv
   ```

   Mac / Linux（ターミナル）:

   ```bash
   python3 -m venv .venv
   ```

3. 仮想環境を有効にする

   有効になると、行の先頭に `(.venv)` と出ます。

   Windows（PowerShell）:

   ```powershell
   .venv\Scripts\Activate.ps1
   ```

   Windows（コマンドプロンプト）:

   ```bat
   .venv\Scripts\activate.bat
   ```

   Mac / Linux:

   ```bash
   source .venv/bin/activate
   ```

4. 必要な部品を入れる

   ```bash
   python -m pip install -r requirements.txt
   ```

   `python` が見つからないときは、`python3 -m pip install -r requirements.txt` を使ってください。

## 2. 使うたびに行う起動

1. アプリのフォルダへ移動する（「1」と同じ `cd`）
2. 仮想環境を有効にする（「1」の手順 3 と同じコマンド）
3. アプリを起動する

   ```bash
   python app.py
   ```

   `python` が見つからないときは `python3 app.py` を使ってください。

4. ブラウザ（Chrome、Edge、Safari など）で次の住所を開く

   http://127.0.0.1:5000

起動した黒い画面は、使っているあいだ閉じないでください。`タスク管理アプリを起動しました` と出れば準備完了です。

## 3. 使い方

1. 「タスクを追加」を押す
2. タイトルを入力する。空欄のままでは保存できない
3. 担当者は一覧から選ぶ。新しい名前を入力して保存すると、その名前が担当者として登録される。空欄なら担当者なし
4. 期限とステータス（未着手 / 進行中 / 完了）を選ぶ
5. 「保存」を押す
6. 画面上部の担当者とステータスで、一覧を絞り込む。件数のボタンを押しても、ステータスで絞り込めます
7. 各タスクの「編集」「削除」で内容を変える、または消す
8. 赤枠と「期限超過」は、完了していなくて期限の日を過ぎたタスク。期限の当日は超過にならない

同じ名前の担当者は、1人として扱われます。

## 4. 止める

起動した黒い画面をクリックして、キーボードで **Ctrl+C** を押します。Mac でも Command ではなく Ctrl です。

ブラウザのタブを閉じただけでは、アプリは動いたままです。

## 5. うまくいかないとき

### 仮想環境を有効にできない（Windows）

PowerShell で「このシステムではスクリプトの実行が無効になっているため…」と出ることがあります。そのときは、同じ画面で次を順に実行してください。この設定は、その画面を閉じると元に戻ります。

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.venv\Scripts\Activate.ps1
```

コマンドプロンプトを使っている場合は、PowerShell 用ではなく次を使います。

```bat
.venv\Scripts\activate.bat
```

`source .venv/bin/activate` は Mac と Linux の書き方です。Windows では使えません。

### 仮想環境を有効にできない（Mac / Linux）

次の書き方を、アプリのフォルダで実行します。

```bash
source .venv/bin/activate
```

`source` が見つからない、またはコマンドとして認識されないときは、Windows 用の書き方を Mac で使っているか、フォルダが違います。Mac は「ターミナル」を使い、先に `cd` でアプリのフォルダへ移動してください。

`python3` が見つからないときは、[python.org](https://www.python.org/downloads/) から Python 3.9 以上を入れて、手順 2 からやり直してください。

### そのほかによくあること

- `No module named 'flask'` と出る  
  仮想環境が有効になっていないか、部品のインストールが終わっていません。行の先頭が `(.venv)` になっていることを確認し、`python -m pip install -r requirements.txt` を実行してください。
- ブラウザでページが開かない  
  アプリを起動した黒い画面が開いたままか確認してください。住所は `http://127.0.0.1:5000` です。`https` にはしないでください。
- `Address already in use` と出る  
  アプリがすでに起動しているか、別のソフトが 5000 番を使っています。起動中の画面で Ctrl+C を押して止めてから、もう一度 `python app.py` を実行してください。
- フォルダが違う  
  `requirements.txt` や `app.py` が見つからないときは、`cd` の場所がアプリのフォルダではありません。

## 6. データの場所

タスクと担当者は、アプリのフォルダの中の次のファイルに入っています。

```text
data/tasks.db
```

アプリを止めても、このファイルがあればデータは残ります。消すときは、先にアプリを Ctrl+C で止めてから、このファイルを削除してください。バックアップするときは、このファイルをコピーします。

## 7. ことばの説明

- ターミナル: 文字でパソコンに命令するための画面。Windows では PowerShell やコマンドプロンプト、Mac ではターミナル
- 仮想環境: このアプリ専用に部品を置く場所。フォルダ名は `.venv`
- pip: Python の部品を入れる道具
- ブラウザ: Chrome、Edge、Safari など、ページを見るソフト
- URL: ページの住所。このアプリでは http://127.0.0.1:5000
- データベース: データをしまうファイル。このアプリでは `data/tasks.db`
- ステータス: 作業の進み具合。未着手、進行中、完了の3つ
- 期限超過: 完了していないのに、期限の日を過ぎている状態

## ファイルについて

消さずに残してください。

- `app.py`: アプリ本体
- `requirements.txt`: 入れる部品の一覧
- `templates` と `static`: 画面の中身と見た目
- `data/tasks.db`: あなたのデータ（使い始めるとできます）
